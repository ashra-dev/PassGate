1. What is this project?

PassGate is a web application for event ticketing and on-site benefit scanning. Organizers create events with ticket tiers and benefits (Entry, Lunch, etc.). Tickets start in a Vault Pool, can be allocated to distributors or sold online, and are redeemed at stalls by scanning QR codes.

Stack: PHP 8.x + PostgreSQL (no separate React frontend). Shared CSS design system in assets/css/passgate.css. Currency: NRS. Timezone: Asia/Kathmandu.

Simple flow: Admin creates event → Vault tickets → Allocate / Sell online → Guest gets QR → Stall scans → Green / Yellow / Red outcome.

5. Correct user journeys

  1. Customer: Create account → (optional View events) → Buy → Pay → My tickets (QR)
  2. Returning customer: Log in → Buy or My tickets
  3. Stall: Staff → stall email/password → Scan QR (redeems benefit)
  4. Admin: Staff → Admin magic link → Dashboard (create event, stalls, allocate, analytics)
  5. Status check: Check ticket status — view only; scanning on terminal redeems

Important rule: Stall name must match the benefit name exactly (e.g. benefit Lunch → stall Lunch).
